# 利用者マニュアル

対象: エンドユーザー（マイニング契約者）

---

## 1. アカウント作成〜初期設定

1. トップページの「無料で始める」からメールアドレスで登録
2. **最初に 2 段階認証を設定してください**（設定 → 2段階認証）
   - Google Authenticator / Authy 等の認証アプリでキーを読み込む
   - 表示されたリカバリーコードを安全な場所に保管する（この画面でしか表示されません）
   - ⚠ 2段階認証を設定しないと**出金できません**
3. 出金には本人確認（KYC）の完了も必要です

## 2. ダッシュボードの見方

| 項目 | 意味 |
|---|---|
| Current Hashrate | いまの実効ハッシュレート（契約分の設備が実際に出している計算能力） |
| Purchased / Allocated | 契約した量 / 実機に割り当てられた量 |
| Active / Offline Miners | 稼働中・停止中のワーカー（設備スライス）数 |
| Est. BTC / Day | 現在の難易度・価格での**推定**日次採掘量 |
| Net Revenue | 電力・手数料を引いた**推定**純収益 |
| 損益分岐 BTC 価格 | これを下回ると赤字になる価格。**常に確認してください** |

「推定」バッジが付いた数値はすべて見込みであり、保証ではありません。
難易度の上昇・価格の下落により、実際の収益は減少し、赤字になることもあります。

## 3. 収益シミュレーター

契約前・契約後いつでも `/simulator` で試算できます。

- スライダーで条件を変えると即座に再計算されます
- **感度分析**（価格 -50% / 難易度 +30% のケース）を必ず見てください
- 「1年間の累積純収益」は難易度が2週間ごとに +1.5% 上昇する前提の試算です

## 4. 出金のしかた

1. **アドレス登録**: ウォレット → 出金先アドレス → 追加
   - アドレスは必ずコピー＆ペーストで（1文字の誤りで資産が失われます。チェックサム検証はありますが過信しないでください）
   - 登録から **24時間はそのアドレスへ出金できません**（乗っ取り対策のクールダウン）
2. **出金申請**: 金額・宛先を選び、2段階認証コードを入力
   - 最低出金額・手数料は画面に表示されます
3. **承認待ち**: 運営の承認後に送金されます（通常 1〜24 時間）
   - 金額が大きい場合や異常検知された場合は、確認に時間がかかることがあります
4. **完了**: 送金後、確認数が画面に表示されます。承認前なら自分で取消できます

## 5. 通知

- ワーカー停止・難易度調整・出金の進行状況はアプリ内通知でお知らせします
- 重要なセキュリティイベント（新しい端末からのログイン等）も通知されます

## 6. よくある質問

**Q. ハッシュレートが契約量より少し低いのはなぜ？**
実機は温度・プール接続状況で常に変動します。稼働率 97〜99% 台が正常範囲です。
大きく低下している場合はワーカー一覧で該当機を確認してください。

**Q. 収益が昨日より減ったのはなぜ？**
主な要因は (1) ネットワーク難易度の上昇 (2) BTC 価格の下落 (3) 設備の一時停止 です。
ネットワークページで難易度の調整履歴を確認できます。

**Q. 表示どおりの収益が保証されますか？**
いいえ。すべて推定値です。損益分岐点を下回る状況では損失が発生します。

**Q. 秘密鍵はどこに保管されていますか？**
本システムはお客様の秘密鍵を保持しません。出金は登録いただいたお客様自身のウォレットアドレスへ送金する方式です。

**Q. パスワードを忘れた / 認証アプリを失くした**
リカバリーコードをお持ちの場合はログイン画面から利用できます（商用版）。
それも失った場合はサポートへ本人確認のうえご連絡ください。

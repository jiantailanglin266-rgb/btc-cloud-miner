## 3. 状態設計（全画面共通）

| 状態 | 表現 |
|---|---|
| Loading | スケルトン（カードの形を保った淡いパルス）。スピナー全画面は使わない |
| Empty | アイコン＋説明＋次の行動ボタン（例:「まだ契約がありません」→「プランを見る」） |
| Error | 赤系トースト＋インライン再試行ボタン。技術的詳細は出さない |
| Degraded | 黄色バッジ「データが N 分前のものです」。値はグレー表示 |
| Unavailable | 該当カードのみグレーアウト。他は正常表示（**画面全体を落とさない**） |
| Estimate | すべての推定値に `推定` チップ＋ⓘツールチップ（算出根拠） |
| Demo | ヘッダに `DEMO` バッジ。Mock データであることを常時明示 |

## 4. デザインテーマ

```
背景      #05070d (base) / #0a0e1a (deep navy) / カード #0f1420
罫線      rgba(255,255,255,.08)
文字      #e8ecf4 (primary) / #8b93a7 (muted)
アクセント Bitcoin Orange #f7931a
          Gold           #ffcc4d
          Electric Blue  #2f7cff
正/負     #22c55e / #ef4444
```

- 角丸 `rounded-2xl`、余白広め、ヘッダは `backdrop-blur`
- グロー: アクセント色の `box-shadow` を薄く（0 0 40px rgba(247,147,26,.18)）
- グラデーション: `linear-gradient(135deg, #f7931a, #ffcc4d)` をキー要素のみに
- 粒子・3D はヒーローとダッシュボード背景に**控えめに**1箇所ずつ（CPU を食わない SVG / CSS）
- **ギャンブル的表現を避ける**: 派手な点滅、カウントアップの過剰演出、「稼げる」訴求をしない
- 数値は等幅数字（`font-variant-numeric: tabular-nums`）で桁揺れを防ぐ

### レスポンシブ

| ブレークポイント | レイアウト |
|---|---|
| < 768px | 1カラム、下部タブバー、グラフは横スクロール |
| 768–1279px | 2カラム、サイドバーはアイコンのみ |
| ≥ 1280px | サイドバー展開 + 3〜4カラムグリッド |

### アクセシビリティ

- コントラスト比 4.5:1 以上（ミュート文字は 3:1 以上の大きさで使用）
- 色だけで状態を伝えない（ONLINE/OFFLINE はアイコン＋テキストも併記）
- キーボードのみで全操作可能。フォーカスリングを消さない
- グラフには表形式の代替（`<table>` を視覚的に隠して提供）

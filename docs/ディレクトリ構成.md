## レイヤリング規約（実装でも lint でも守る）

| ルール | 理由 |
|---|---|
| `app/` からビジネスロジックを書かない。`modules/` を呼ぶだけ | 画面とロジックを分離し、テストと再利用を可能にする |
| Prisma は `lib/store/prisma.ts` 以外から import しない | DB 実装を差し替え可能に保つ |
| 外部 SDK / fetch は `modules/*/adapters/` からのみ | 外部依存の影響範囲を局所化する |
| `modules/revenue/engine.ts` は他モジュールを import しない（純関数） | ユニットテストで固定でき、監査可能にする |
| Server Component は `lib/store` を直接呼ぶ（自分の API を fetch しない） | 往復を減らし初期表示を速くする |
| Client Component は `fetch('/api/...')` を使う | 認可がサーバー側で必ず効く |
| `tenantId` は必ず関数の引数として明示的に渡す | 暗黙のグローバルを禁止し、越境バグを型で防ぐ |

## 命名規約

- ファイル: `kebab-case.ts` / React コンポーネント: `PascalCase.tsx`
- 型: `PascalCase`、定数: `SCREAMING_SNAKE_CASE`
- BTC 金額の変数名は必ず `...Btc` を付ける（`amount` 単独を禁止 — 単位事故の防止）
- ハッシュレートは必ず `...Ths`（TH/s）で統一

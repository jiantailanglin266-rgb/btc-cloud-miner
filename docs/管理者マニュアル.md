# 管理者マニュアル

対象: 運営担当者（PLATFORM_ADMIN / TENANT_ADMIN / SUPPORT）

---

## 0. はじめに

管理コンソールは `/admin` にあります。管理ロールでログインし、右上メニューから「管理コンソール」を選択してください。

| ロール | できること |
|---|---|
| PLATFORM_ADMIN | すべて（全テナント・出金承認・プロバイダー・監査） |
| TENANT_ADMIN | 自テナントの管理・出金承認・ブランディング・料金 |
| SUPPORT | 閲覧のみ。**出金の承認・却下・設定変更はできません** |
| AUDITOR | 監査ログの閲覧のみ |

⚠ **管理者は必ず2段階認証を設定してください。** 出金承認・権限変更は 2FA なしでは実行できません。

## 1. 初期セットアップ（本番）

1. デモ seed は使わず、以下を手動または初期化スクリプトで作成する
   - `tenants` に自社テナント 1 行
   - `tenant_settings` に手数料・出金ポリシー
   - 管理者ユーザー（作成後すぐ 2FA を有効化）
2. `/admin` を開き、「本番構成の警告」がゼロであることを確認
3. `/admin/providers` でプロバイダーを登録し、接続を確認
4. `/admin/plans` で販売プランを確認

## 2. 出金の承認（最重要業務）

`/admin/withdrawals` の「要対応」タブに承認待ちが並びます。

### 判断の手順

1. **リスクスコアと検知理由を読む**（新規アドレス / 金額急増 / 新規 IP など）
2. スコア 50 以上（FLAGGED）は特に慎重に。必要ならユーザーへ別経路（登録メール）で本人確認する
3. 宛先アドレス・金額・手数料を確認する
4. メモを記入し、自分の 2FA コードを入力して「承認」または「却下」
5. 閾値超・高リスクは 2 人目の管理者の承認が必要（あなたの承認だけでは送金されない）

### ルール（システムが強制するもの）

- 自分が申請した出金は承認できない
- 同じ出金に 2 回承認はできない
- 却下時は理由の記入が必須。保留残高は自動でユーザーに返る
- すべての操作が監査ログに残る

### こんなときは承認しない

- 深夜に登録直後のアドレスへ全額出金
- 同一 IP から複数アカウントの出金が同時に発生
- KYC 情報と挙動が一致しない
→ 迷ったら却下し、サポート経由で本人確認を行ってください。出金は後からでもできます。

## 3. KYC 審査

`/admin/users` でユーザーの KYC ステータスを変更します。

| 遷移 | 操作 |
|---|---|
| `PENDING` → `APPROVED` | 外部 KYC ベンダーの審査結果を確認して承認 |
| `PENDING` → `REJECTED` | 書類不備・本人確認不能 |
| `APPROVED` → `EXPIRED` | 定期的な再確認（1〜3年ごと）で期限切れに |

`APPROVED` 以外のユーザーは出金できません。

## 4. プロバイダー管理

`/admin/providers`

- **メンテナンスにする**: 計画停止時。呼び出しが止まり、無駄な失敗を記録しない
- **無効にする**: 契約終了時
- **今すぐ統計を同期する**: 手動でワーカー統計を取り込む（通常は5分ごとの自動同期）
- 新規プロバイダーの接続は開発者ガイド §4 を参照（アダプタの実装が必要）

## 5. 障害対応

- `/admin/health` で全依存の状態と circuit breaker を確認
- ユーザー影響がある場合は `/admin/incidents` … MVP では API（`create-incident`）から作成
- 対応手順の詳細は OPERATIONS.md のランブック参照

## 6. テナント（ホワイトラベル）

`/admin/tenant` で自テナントのブランディングを変更できます。

- サービス名・ロゴ文字・カラー 2 色（プレビュー付き）
- プラットフォーム手数料率・プール手数料率・電力単価
- 最低出金額・出金手数料

変更は即時反映されます。手数料の変更は**新しい計算から**適用され、過去の確定報酬には影響しません。

## 7. 監査ログ

`/admin/audit` で全操作の履歴を確認できます。ログは追記専用で、管理者でも削除・変更できません。
不正調査の際は、対象ユーザー・対象期間・action で絞り込んでください。
